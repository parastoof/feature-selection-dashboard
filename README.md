# Feature Selection Dashboard

An interactive Streamlit dashboard for exploring and comparing
feature selection techniques for machine learning.

## Features

- Upload CSV or Excel datasets
- Classification and regression support
- Multiple feature selection methods
- Feature ranking and comparison
- Model evaluation before and after feature selection

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
